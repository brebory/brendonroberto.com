brendonroberto.com
===

My personal website, with a biography and links to my socials.
I also have various projects and experiments in some of the subfolders, but I'll eventually move those elsewhere.

## Local preview

The site is plain HTML and CSS and deploys as-is, with no build step. Vite is only used to serve it locally:

```sh
npm install
npm run dev
```

This opens the site in your browser and reloads it as you edit files.
